📚 Book Registration Application
A dynamic web-based application built using Java, Thymeleaf, and HTML that allows users to register books with essential details and manage them through a user-friendly interface.
 It is structured with standard Java servlets, JSP, Thymeleaf for templating, and follows the MVC design pattern.

🔧 Tech Stack
Backend: Java (Servlets), JDBC

Frontend: HTML, CSS, Thymeleaf

Database: MySQL

Tools: Eclipse/VS Code, Git, GitHub

Build Tool: Manual configuration / Ant (if used)

✅ Features
Register new books with title, author, genre, etc.

View a list of all registered books

Update book information

Delete existing book entries

Simple and clean UI using Thymeleaf templating

Database integration using JDBC
